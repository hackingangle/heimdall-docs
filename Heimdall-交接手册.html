2. 产品定位（接手前先读懂这一段）

Heimdall 是 YouTube 口播稿创作工作台，也是外部 Agent（Claude Code / Cursor / OpenClaw / Hermes）的共享数据层。 设计哲学是机制与策略分离：后端只存数据、守规则；怎么调研、怎么写稿，交给外部 Harness 或平台内的 Agent。

1.0 验证场景：用户建一期节目 → 收集素材（人手 / API / PDF）→ 用 Agent 基于素材创作 → 产出仍是素材 → 提词录制。

核心决策：创作结果即素材。没有独立的「产物 / Generation / Task 黑板」实体。手动录入、外部 Agent 写入、AI 生成，全部落在 Material 一张表，用 source = manual | api | generated 区分。

3. 基础板块功能

网页（www.agoodbit.com）与 iOS 客户端板块对齐。下面按「用户能做什么」写，而不是按文件名写。

账号与准入

谁能进系统

  • 注册 / 登录 / 退出；JWT 会话
  • 生产环境注册需要暗号 invite_code（HEIMDALL_REGISTRATION_PASSPHRASE）
  • 个人资料：显示名、emoji 头像（前后端预设必须对齐）
  • 软删 / 封禁由后端 User 模型支撑

项目（节目期）

路由 /projects · iOS Tab「项目」

  • 一期节目 = 一个 Project：episode_no + 标题 + 分类
  • episode_no 按用户隔离，缺省取 max+1，冲突 409
  • 列表 CRUD；点进详情进入工作台

素材库

项目详情左侧。唯一内容实体

  • 文本录入 / 编辑 / 删除；Markdown 预览
  • 按来源 Tab 筛选：手动 / API / AI 生成
  • PDF 等原件上传到 OSS 或本地盘；DB 只存 key
  • PDF 自动抽取正文（PyMuPDF）；扫描件标 failed，等后续 OCR
  • 列表分页、摘要不回全文（性能已处理过）

AI 创作

项目详情右侧 CreationPanel

  • 选 Agent + 勾选已 ready 的素材 + 补充指令
  • POST 素材时带 agent_id，立即返回 generating
  • 后台调 OpenAI 兼容 LLM，回填 ready / failed
  • 前端有 generating 行时每 2 秒轮询素材本身
  • 产出仍是素材，可再当下一轮输入（链式创作）

智能体 Agent

路由 /agents · 平台级、按用户隔离

  • 名称、用途、系统提示词
  • 绑定一条用户自己的 LLM 配置；空则用全局默认
  • 外部 Harness 也可读 Agent 定义来执行创作

LLM 配置

用户菜单 → 模型接入

  • 用户维度：name / base_url / api_key / model
  • 响应里 api_key 只回掩码
  • 删除配置后，引用它的 Agent 回退全局默认

API Token

给外部 Agent 用的钥匙

  • 签发时明文只展示一次，形如 hd_…
  • 库里只存 sha256；列表展示 prefix
  • 可吊销；同一 Bearer 头，hd_ 走 Token，否则走 JWT
  • Token 通道写入的素材 source=api

技能引导

路由 /guide

  • 教用户在 Claude Code / Cursor / OpenClaw / Hermes 装技能
  • 一键脚本：docs/skills/claude-code/setup-heimdall.sh
  • 三件套：doctor（自检）/ collect（调研编排）/ material（入库规范）

提词器 · Web

素材详情里打开，面向录制

  • 深色大字、按段落渲染
  • 定速自动滚动（空格暂停，速度/字号本地持久化）
  • 点击段落定位，方便分段重录
  • Web 没有跟读 ASR

提词器 · iOS 跟读

客户端独家能力

  • 麦克风 PCM → wss://www.agoodbit.com/asr/
  • 说到哪滚到哪：ScriptFollower 对齐口播稿
  • 口令「回上一句」；诊断页看识别原文
  • 近期方向：去掉手动/定速，只保留跟读（见进行中分支）

诊断

排障用，不是业务实体

  • Web：DebugPanel；顶栏显示「前端 vN · 后端 vM」
  • iOS：独立「诊断日志」窗口 + FAB；可改 API / ASR 地址

5. 架构与数据流

浏览器 / iOS 客户端 │ HTTPS https://www.agoodbit.com ▼ Nginx（heimdall-backend 部署） ├─ / 前端静态（heimdall-frontend 单独 Deploy） ├─ /api /health FastAPI（server/） └─ /asr/ include 片段 → heimdall-asr WebSocket iOS 跟读：麦克风 PCM ──WSS──► asr/server.py ──NLS──► 阿里云 ISI 只回 partial / final，不落盘、不知项目 外部 Agent：Bearer hd_xxx ──► 同一套 /api（projects / materials / agents） AI 创作：前端勾选素材 → POST material(agent_id) → BackgroundTasks → LLM → 回填 Material

后端技术栈

Python 3.11 · FastAPI · SQLAlchemy 2.0 · Alembic · Pydantic v2 · uv · MySQL 8 · 阿里云 OSS。质量门禁：ruff + mypy --strict + pytest。make check 必须绿。

前端技术栈

React 19 · TypeScript · Vite · Ant Design · TanStack Query · axios。分层：pages → hooks → api。组件不直接打接口。npm run check 必须绿。

客户端技术栈

SwiftUI，Xcode 工程在 heimdall/。Stores + Networking 对齐 REST。跟读链路：AudioCapture → StreamingASRClient → ScriptFollower → TeleprompterController。

ASR

ASR_MODE=isi（推荐）/ mock / dashscope。生产走阿里云智能语音交互。健康检查：https://www.agoodbit.com/asr/health。

7. 生产环境与发布纪律

项值
站点https://www.agoodbit.com
API 健康curl https://www.agoodbit.com/health
ASRwss://www.agoodbit.com/asr/ · /asr/health
ECS见各仓 deploy/README.md 的 DEPLOY_HOST（GitHub Secrets，勿写进业务代码）
生产只允许 CI 部署。禁止本机跑 deploy.sh、rsync、scp 或手工 SSH 改代码。 入口只有三个 GitHub Actions Deploy workflow：heimdall-backend、heimdall-frontend、heimdall-asr。 密钥只存在各仓 Settings → Secrets，不提交 production.env。

日常发布：推 main → CI 全绿会自动 Deploy；也可在 Actions 里手动 Run workflow。首次顺序：先 backend（基础设施 + API），再 frontend，再 asr（Nginx 通过 include /etc/nginx/heimdall-includes/*.conf 挂 ASR）。

各仓 Deploy 所需 Secrets 名称见：

  • server/deploy/README.md（数据库、JWT、OSS、LLM、注册暗号、CORS）
  • web/deploy/README.md（VITE_API_BASE + SSH）
  • asr/deploy/README.md（NLS / 阿里云 AK）

版本号

顶栏 Tooltip 显示「前端 vN · 后端 vM」。N、M 分别来自 web/VERSION、server/VERSION，必须是递增整数。

  • 改了 web/ 功能 → 同一 commit 把 web/VERSION +1
  • 改了 server/ 功能 → 同一 commit 把 server/VERSION +1
  • 两边都改 → 两个仓各自 +1、各自提交
  • 纯文档 / 纯规则、不改行为 → 不必 bump

8. 工程约定（违反就会把系统做复杂）

  • 简单、高可用。不为假想需求预留抽象。每个实体、字段、端点都要能回答「删掉会怎样」。
  • 后端：路由薄、服务厚、模型纯。业务规则只活在 services/，不要在 service 里 raise HTTPException。
  • 前端：组件纯 props；页面才组合 hooks。缓存键集中在 hooks 的 xxxKeys。
  • iOS：项目流的 navigationDestination 必须挂在根 NavigationStack，子页再挂一层会导致素材点击静默失败。
  • 加依赖：后端用 uv add，前端用 npm install，不要手改锁文件意图。
  • 各仓 AI 工作约定：server/CLAUDE.md、web/CLAUDE.md（比根 README 新；根 README 仍停留在早期脚手架表述，以 CLAUDE.md 和代码为准）。
